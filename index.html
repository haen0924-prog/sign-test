사용설명서

  

    
1. 처음 한 번 설치

    
    
      
  1. supabase.com에서 가입하고 New project로 프로젝트를 만듭니다. 데이터베이스 비밀번호는 메모해 두세요.
    2. 
      
  2. 이 앱의 연결 설정에서 설치 SQL을 복사해 Supabase SQL Editor에 붙여넣고 Run을 누릅니다.
    3. 
      
  3. Project Settings → API에서 Project URL과 anon public key를 붙여넣고 [연결 확인]을 누릅니다.
    4. 
      
  4. 이메일로 강사 계정을 만들고 로그인합니다.
    5. 
    

    
2. 시험 만들기

    
    
      
  • + 새 시험을 누르고 제목, 응시 시작 시각을 정합니다.
    • 
      
  • 문항을 추가하고 객관식은 정답 보기를 ●로 고릅니다.
    • 
      
  • 💾 저장을 누른 뒤, 시험 당일에 🔗 링크 복사로 학생에게 보냅니다.
    • 
    

    
3. 채점

    
[📋 제출·채점]에서 학생 목록을 보고, 주관식은 맞으면 체크합니다. 객관식은 자동으로 채점됩니다.

    
4. 영상과 용량 주의

    
    
      
  • 영상은 10MB 이하, mp4 또는 webm으로 올려 주세요. 긴 영상은 유튜브 링크를 권장합니다.
    • 
      
  • 끝난 시험은 시험 삭제로 지우세요. 시험과 함께 영상도 지워집니다.
    • 
      
  • 한 달에 한 번 Supabase의 Usage에서 사용량을 확인하세요. 80%를 넘으면 정리하세요.
    • 
    

    
5. 꼭 지켜 주세요

    
    
      
  • 데이터베이스 비밀번호와 service_role 키는 누구에게도 알려 주지 마세요.
    • 
      
  • 학생 링크는 시험 당일에만 보내세요.
    •

    2.

    3. 
      
  3. 헷갈리는 문제는 ⚠ 애매함에 체크하세요.
